Post Writer

The pony express for ink.

Write a note on your Supernote. Send it to someone on the tailnet. They pull it onto their own Supernote, strokes and all.

No accounts, no sign-in: the tailnet already knows who is holding the device. Anyone who has opened Post Writer once is a recipient.

Install on your Supernote

  1. Make sure the Supernote is on the tailnet (Tailscale app installed and connected) and on the plugin-preview firmware.
  2. Copy postwriter.snplg into the device's MyStyle folder (USB, Supernote Partner app, or adb push).
  3. On the device: Settings › Apps › Plugins › Add Plugin, pick postwriter.snplg, tap Install.
  4. Open any note, tap the puzzle icon in the sidebar, choose Post Writer. Grant network and file access; pick Always Allow so it only asks once.

Reinstalling a newer .snplg the same way is an in-place upgrade.

If something goes wrong

  • The download is called postwriter.snplg.zip (older Safari downloads did this): the file is fine, rename it back to postwriter.snplg. If Safari unpacked it into a folder, download it again — the installer wants the package, not its contents.
  • It installed but there is no Post Writer row in the puzzle menu: the plugin registers that row itself the first time it runs, so install the current .snplg again (an in-place upgrade) and reopen a note. If it still is not there, restart the device, then open an issue with your firmware and PluginHost versions.
  • The plugin opens but says it does not know you: Tailscale is not connected on the Supernote. Connect it and tap Refresh.

Use it

  • Send: with a note open, open Post Writer and tap a person under Send to. The whole note goes: every page, every stroke, pen and pressure included.
  • Inbox: switch to the Inbox tab and tap Pull (or Pull all). The note is rebuilt in your INBOX folder and opens on screen.
  • Sending to yourself works too. It is a quick way to copy a note into INBOX, and a one-device way to try the whole loop.
  • This page's inbox view shows what is waiting for you and what you have sent, from any browser on the tailnet.

How it works

The Supernote plugin SDK exposes a note as elements (strokes with points and pressure, text boxes), not as a file, so Post Writer serialises those page by page, with geometry normalised so a note lands correctly on a different device size. The service is a small worker on the tailnet that holds the note until the recipient pulls it; delivery is acknowledged only after the note is written on the receiving device, so a dropped connection never loses a note. Templates, links, titles and images do not travel yet.

From the command line

adb push postwriter.snplg /storage/emulated/0/MyStyle/
curl https://postwriter.tailb55c1.ts.net/api/me      # who the tailnet says you are
curl https://postwriter.tailb55c1.ts.net/api/inbox   # what is waiting for you
